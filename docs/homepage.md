# 主页与安装器下载

- 主页为域名根目录，提供买卡与下载安装器入口，不展示管理目录。
- 管理后台左侧“主页设置”：买卡链接、可选通用下载链接、按游戏上传安装器。
- 按游戏上传后，主页下载按钮指向游戏安装器列表；未上传时使用通用下载链接，均未配置时显示下载即将开放。
- 文件允许 TIPA/IPA，检查 ZIP 与 Payload/*.app/Info.plist 结构，不执行或解压，不替代真机兼容测试。请由管理员确认上传的是编译完成的安装器。
- 上传至私有 content-addressed objects，由 /installer?game_id=数字ID 输出当前安装器附件。辅助包发布状态不受影响。
- 替换安装器不物理删除旧对象。沿用现有服务器/PHP 上传上限与 CDN 上传限制。
- 买卡/下载地址限制 HTTPS，不接受 URL 内嵌账号密码。全局设置有版本冲突校验，上传需要管理员登录和 CSRF。
- 状态存现有 state.json 的 home / home_installers 字段，不需要数据库。
- 新路由 /、/home.css、/installer 需交给 public/index.php。若部署站点使用硬编码路由白名单，增加上述三个路由及管理目录 home.php；保持私有目录与其他未知路径默认拒绝。
