## 游戏 ID 复测

- 删除旧 JSON 自动迁移；正常访问不改写状态，缺失 ID 的状态报错且不自动补齐。新增游戏忽略外部指定 ID，使用单调计数器，失败创建不消费 ID。两个进程并发创建得到不同 ID。
- 更新、票据及后台只接受 game_id；app/app_key 单独或混合传入均返回 422，公开响应和导出头文件没有 app_key。
- 缺少数字 ID 的旧签名响应和旧票据均被客户端拦截。导出工具按 ID 自动填写游戏身份和共用无查询参数 URL；新版安装器及助手核对签名中的整型 ID，拒绝其他游戏与布尔值冒充 ID。
- 发布序号按游戏 ID 分开保存；旧全局序号不导入，其他游戏的历史序号不干扰当前游戏；当前游戏的序号回退仍被拦截。
- 本机浏览器确认共用接口、当前三角洲 ID 1、自动编号的新增表单；没有创建测试业务游戏或发布现有真实包。
